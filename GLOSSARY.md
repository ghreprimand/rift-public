# Rift

Rift is a shared place for moving and organizing notes and attachments between devices. Workspaces organize the content, and one shared session keeps the open views consistent across connected devices.

## Language

**Card**:
A note or attachment displayed in a workspace.
_Avoid_: Item in user-facing descriptions

**Attachment**:
An original file associated with a card.
_Avoid_: Preview, thumbnail

**Preview**:
A lightweight representation of an attachment that helps identify it before opening or downloading the original.
_Avoid_: Original

**Group**:
A named collection of related cards within one workspace.
_Avoid_: Workspace, folder

**Workspace**:
A named place containing cards and groups, shown as a canvas or a library.
_Avoid_: Tab, group

**Canvas**:
The spatial view of a workspace, with cards arranged at chosen positions.
_Avoid_: Workspace when describing only its presentation

**Library**:
The searchable, sortable list or grid view of the same cards in a workspace.
_Avoid_: A separate copy of the workspace

**Tab**:
An open view of a workspace in the shared session. Closing a tab does not delete the workspace.
_Avoid_: Workspace when referring only to an open view

**Shared session**:
The common open tabs, active tab and view followed by every connected device.
_Avoid_: Independent per-device session

**Inbox**:
The default workspace for captures that have not yet been organized elsewhere.
_Avoid_: Trash, archive

**Archive**:
Cards or workspaces set aside from normal browsing while their contents remain available.
_Avoid_: Trash, permanent deletion

**Trash**:
Deleted cards retained temporarily for restoration before permanent removal.
_Avoid_: Archive

**View control**:
The temporary right to direct the shared camera or selection while other devices follow.
_Avoid_: Independent view
